PDF ↔ PNG 변환

PDF → PNG (페이지별 이미지)

각 페이지를 PNG로 추출합니다. 여러 장이면 ZIP으로 묶어 저장합니다.

PNG → PDF (여러 이미지를 하나로)

여러 이미지를 순서대로 한 개의 PDF로 합칩니다. 드래그로 순서를 바꿀 수 있어요.

    CSV → XLSX 변환

    CSV 파일을 엑셀(.xlsx)로 변환합니다. 모든 값은 텍스트로 유지되어 0으로 시작하는 숫자나 날짜가 변형되지 않아요.

    파일명 수정

    맥에서 깨진 한글 파일명(자모가 분리되는 NFD 문제)을 자동으로 고칩니다. 이름을 직접 바꿀 수도 있어요. 파일 내용은 그대로 유지됩니다.

      엑셀 편집

      xlsx·csv를 표에서 바로 편집하고 다시 저장합니다. 값은 텍스트로 유지돼요(0으로 시작하는 숫자·날짜 보존). 소~중간 규모에 적합합니다.

      대용량 CSV 편집 WASM · DuckDB

      수십만~수백만 행 CSV도 브라우저에서. 페이지 단위로 편집하고 WHERE 조건으로 필터한 뒤 다시 CSV로 저장합니다. 최초 1회 DuckDB(WASM) 로딩에 수 초 걸려요.

      화살표 이동 · Shift+화살표 범위선택 · Enter 편집 · ⌘/Ctrl+C/V 복사·붙여넣기 · Del 지우기 · Esc 취소 · 헤더 경계 드래그=열너비(더블클릭=자동맞춤)

      HWPX 뷰어

      한컴오피스 .hwpx 문서의 내용(문단·표·이미지)을 브라우저에서 바로 봅니다. 서식은 단순화되어 표시되며, 구형 .hwp(바이너리) 형식은 지원하지 않습니다.
